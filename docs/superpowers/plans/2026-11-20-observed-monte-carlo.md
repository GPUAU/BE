# 실제 관측 기반 몬테카를로 구현 계획

**목표:** 동일 오퍼의 검증된 실제 월별 이력으로 Spring에서 가격과 목표 IRR을 계산하고 기존 화면에 연결한다.

1. 수집 관측과 환산·출처를 오퍼별로 조회한다. UTC 완료 월의 마지막 유효 관측만 사용하고 최소 12개 연속 월, 양수 가격, 동일 환산 규칙, 가격 변동을 검증한다.
2. API-18·19에 실제 이력 선택을 추가하고 샘플 동작과 실제 결과의 근거·시간·해시를 명확하게 구분한다. 이력 부족은 계산하지 않는다.
3. 기존 프런트의 실제 예측 화면을 Spring에 연결하고 실제 선택 상품·출처와 결과를 함께 표시한다. 실제 이력에 기반하지 않은 가상 결과는 대신 표시하지 않는다.
4. 단위·통합·실제 데이터 HTTP 및 브라우저 검증을 수행한다. 실데이터 이력이 부족하면 부족 상태를 검증하고 충분한 합성 픽스처로 성공 경로를 별도 검증한다.
